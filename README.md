# Dub Siren MK-1

A dub siren synthesizer (Web Audio API). You can install it on iPhone two ways:

1. **As an installable web app (PWA)** — no Xcode, no Mac, no TestFlight. This is the recommended path if you just want it on your iPhone now. See [Install on iPhone without Xcode](#install-on-iphone-without-xcode-pwa) below.
2. **As a native app with Capacitor + Xcode** — needs a Mac. See [Build as a native iOS app](#build-as-a-native-ios-app-needs-a-mac) below.

## Structure

```
www/                     web code (the app itself: HTML/CSS/JS, no dependencies)
  index.html
  style.css
  app.js
  manifest.json          PWA manifest (icon, name, standalone mode)
  sw.js                  service worker: caches the app for offline use
  icons/                 PWA icons
.github/workflows/pages.yml  publishes www/ to GitHub Pages on every push to main
capacitor.config.json    Capacitor configuration (appId, appName, webDir)
ios/                     native Xcode project, generated by Capacitor
```

`www/` is a normal, self-contained web app: you can open `www/index.html` directly in a browser to try the sound without installing anything.

## Install on iPhone without Xcode (PWA)

This whole setup can be done from Windows (or any OS) — no Mac needed.

**Publish the app (one time, from GitHub, in the browser):**

1. On `github.com/jamm87/portable-siren` → **Settings** → **Pages**.
2. Under "Build and deployment" → "Source", pick **GitHub Actions** (not "Deploy from a branch").
3. That's it: the `.github/workflows/pages.yml` workflow automatically publishes the contents of `www/` on every push to `main`. You can watch progress in the repo's **Actions** tab; once it finishes, the URL appears under Settings → Pages, in the form `https://jamm87.github.io/portable-siren/`.

**Install on the iPhone:**

1. Open that URL in **Safari** on the iPhone (it has to be Safari, not Chrome or another browser — only Safari can install web apps on iOS).
2. Tap the **Share** icon (the square with an arrow pointing up).
3. Scroll down and tap **"Add to Home Screen"**.
4. Confirm the name ("Dub Siren") and tap **Add**.

You'll get a home screen icon that opens full-screen (no Safari address bar), with the same gold icon as the native app, and it works offline thanks to the service worker. Every time you update `www/` and push to `main`, the deploy repeats automatically; to see the changes on the iPhone, just reload the page once while online (the service worker updates itself) or remove and re-add the icon if you need to force it.

## Build as a native iOS app (needs a Mac)

## Requirements

- Node.js 18+ and npm (for Capacitor).
- **macOS with Xcode** to build/sign/run the iOS app — this step cannot be done from Linux/this environment, only the project generation and syncing can.
- An iPhone (tested targeting an iPhone 12 mini) with a Lightning/USB-C cable, or the same Wi-Fi network as the Mac.
- A regular, free Apple account to sign the app and install it on your own device — you do **not** need to pay for the Apple Developer Program (99 $/year) for this.

## Getting started (on a Mac)

```bash
git clone <this repo>
cd portable-siren
npm install
npx cap sync ios
open ios/App/App.xcodeproj
```

Capacitor 8 uses Swift Package Manager instead of CocoaPods, so there's no need for `pod install`: just open `App.xcodeproj` (there's no `.xcworkspace`) and Xcode resolves the dependencies on its own.

## Running it on your iPhone 12 mini

1. Connect the iPhone to the Mac via cable (or enable it over the network: Xcode → Window → Devices and Simulators → your iPhone → "Connect via network").
2. In Xcode, select the **App** target and, at the top, choose your iPhone as the destination (instead of the simulator).
3. **Signing & Capabilities** tab of the App target:
   - Check "Automatically manage signing".
   - Under "Team" pick your personal Apple ID (if it's not listed, add it in Xcode → Settings → Accounts). Xcode will create a free "Personal Team".
4. Press ▶️ Run. Xcode builds, installs, and launches the app on the iPhone.
5. **The first time, the iPhone will block the app** for not being from a trusted developer: go to Settings → General → VPN & Device Management → tap your developer Apple ID → Trust. Launch it again from the home screen or from Xcode.

Note: free signing profiles expire after 7 days; after that you'll need to build/install again from Xcode (nothing is lost, it's just a limitation of free signing versus paid signing).

## After changing something in `www/`

Every time you edit `www/index.html`, `style.css`, or `app.js`, sync again before building in Xcode:

```bash
npx cap sync ios
```

## Publishing to the App Store (later, not now)

This isn't set up yet. When the time comes you'll need:
- An Apple Developer Program account (paid).
- Final icon/splash assets in the sizes App Store Connect requires (the current ones in `ios/App/App/Assets.xcassets` are fine for development/TestFlight).
- Archiving the app in Xcode (Product → Archive) and uploading it via TestFlight/App Store Connect.

## Using the app

- Hold your finger on the center plate: the horizontal axis changes **pitch**, the vertical axis changes the **sweep rate**.
- **Latch** keeps the siren sounding without holding your finger down.
- **Feedback** drives the echo feedback to maximum while held.
- **SIREN** controls (waveform, sweep shape, pitch, rate, depth, spread), **ECHO** (time, repeats, tone, send), and **OUT** (volume).
- Quick presets: AIR RAID, POLICE, LASER, UFO, WHOOP, STEPPA.
