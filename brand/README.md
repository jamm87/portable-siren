# Portable Dub Siren — brand mark

`logo-square-wave.svg` is the master logo: a two-tone siren drawn as a square
wave, amber on the dark ground. It uses `currentColor`, so set `color` to
recolour it (`#F2B233` on `#0B0D08` dark, `#1A1206` on `#E8931A` amber).

The app, PWA and site icons (`www/icons`, `site/icons`) and the Android
adaptive icon (`android/.../mipmap-*`, background colour `#0B0D08`) are all
rendered from this mark. Regenerate them from this file if the mark changes.

## Store assets

`play-feature-graphic.png` — the Google Play feature graphic, 1024×500 (the
banner at the top of the listing). Rendered from `feature.html` in the logo
scratchpad; the mark, grid and background square-wave motif all use the brand
tokens.
